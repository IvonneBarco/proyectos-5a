API-SAN

API SAN (Sistema Académico de Navegación) es una API orientada a la búsqueda, consulta y comparación de ofertas académicas. A partir de una carrera y diferentes parámetros definidos por el usuario, como ubicación, costo, modalidad de estudio, entre otros, la API identifica las universidades que ofrecen dicho programa y determina cuáles se ajustan mejor a sus preferencias y necesidades.
