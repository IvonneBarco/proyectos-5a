OptiFauna

OptiFauna es un backend desarrollado como una API REST especializada en el procesamiento y gestión de telemetría IoT aplicada al sector ganadero. El sistema permitirá administrar el inventario de animales, realizar el monitoreo de diferentes aspectos relacionados con su salud y procesar los datos obtenidos mediante dispositivos IoT para identificar situaciones que requieran atención. Además, contará con un sistema de generación de alertas automatizadas para facilitar la detección oportuna de eventos relevantes. El proyecto estará enfocado principalmente en la lógica de negocio, el procesamiento de datos y la escalabilidad del backend, sin requerir el desarrollo de una interfaz frontend.
