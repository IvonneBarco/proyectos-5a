PetCare - Sistema de Gestión Veterinaria y Cuidado de Mascotas

Backend Architecture | RESTful API & Veterinary Management Systems

PetCare es un sistema de software diseñado para facilitar el cuidado, control clínico y seguimiento integral de mascotas. La plataforma permite registrar información individual de cada mascota como especie, raza, edad, peso, esquemas de vacunación, alimentación, medicamentos, controles veterinarios y próximas citas, manteniendo un historial clínico completo[cite: 9]. Desarrollado con una arquitectura Backend robusta, enfocada en la seguridad de la base de datos relacional y un consumo eficiente de APIs RESTful[cite: 9].
